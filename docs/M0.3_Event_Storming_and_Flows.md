# M0.3 — Event Storming, Regras de Comunicação e Core Flows

## 1. Regra Arquitetural de Comunicação (Sync vs Async)

Para evitar que o sistema se torne uma teia de chamadas bloqueantes:

- **Assíncrono (Event/Command Bus via Redpanda/Kafka):** Para reações, efeitos colaterais, processamento pesado e notificações (ex: `IncidentCreated`, `ExecuteActiveResponseCommand`).
- **Síncrono (gRPC):** EXCLUSIVO para decisões que bloqueiam o fluxo de execução e exigem resposta imediata (ex: `ValidatePolicyQuery` no Security Kernel, `CalculateRiskQuery` no Risk Engine).

## 2. Fluxo Principal: Detecção, Triagem, Resposta e Auditoria

```mermaid
sequenceDiagram
    autonumber
    actor Hacker
    participant WZ as Wazuh (Tool)
    participant CON as Connector (ACL)
    participant EB as Event Bus
    participant CORE as Core Platform
    participant RISK as Risk Engine
    participant AI as AI Gateway
    participant SOC as Dashboard SOC
    participant POL as Security Kernel (Policy/Audit)
    participant CB as Command Bus

    Hacker->>WZ: Executa malware (ex: LSASS dump)
    WZ->>CON: Envia raw alerts (Webhooks)
    CON->>CON: Valida payload e gera CorrelationKey (Hash)
    CON->>EB: Publica: SecurityEventReceived (Lote deduplicado)

    EB->>CORE: Consome: SecurityEventReceived
    CORE->>CORE: Verifica CorrelationKey (Idempotência/DB)
    alt Evento Duplicado
        CORE->>CORE: Anexa evento à Timeline
    else Evento Novo
        CORE->>EB: Publica: IncidentCreated (Status: Novo)
    end

    CORE->>RISK: gRPC: CalculateRiskQuery(AssetID, CVSS)
    RISK-->>CORE: Retorna Score (Criticidade: ALTA)
    CORE->>EB: Publica: RiskCalculated

    EB->>AI: Consome: RiskCalculated + IncidentCreated
    AI->>AI: LLM lê logs, consulta Playbooks
    AI->>EB: Publica: SuggestionGenerated (Ação: Isolar Host)

    EB->>SOC: Push WebSocket (Alerta + Sugestão IA)
    SOC->>CORE: Analista aprova Suggestion (API Call)

    CORE->>POL: gRPC: ValidatePolicyQuery(Token, Action, Target)
    POL-->>CORE: PolicyAllowed
    POL->>EB: Publica: AuditRecorded (Trilha Imutável LGPD)

    CORE->>CB: Publica: ExecuteActiveResponseCommand

    CB->>CON: Consome: ExecuteActiveResponseCommand
    alt Sucesso
        CON->>WZ: Aciona API do Wazuh (Isolar IP)
        CON->>EB: Publica: CommandExecuted
        EB->>CORE: Consome: CommandExecuted
        CORE->>EB: Publica: IncidentStatusChanged (Mitigado)
    else Falha
        CON->>EB: Publica: CommandFailed (Timeout)
        CORE->>SOC: Alerta Crítico SOC (Intervenção Manual)
    end
```

---

## 3. Regra de Ouro da IA

A IA **nunca** altera o estado do banco. O fluxo obrigatório é:
`IA -> Gera Suggestion -> Converte em Command -> Core -> Validação (Policy Engine) -> Execução -> Gera Event -> Persistence.`
