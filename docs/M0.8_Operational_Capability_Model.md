# M0.8 — Modelo Operacional, Capacidades, Governança e Evolução da Plataforma

**Versão:** 1.0.0  
**Status:** Ratificado pelo Comitê de Arquitetura

## 1. Modelo de Maturidade por Capacidades (M0 a M9)

A evolução do **GovSec Shield** é governada por evidências e atingimento de KPIs/SLOs operacionais:

| Nível | Capacidade | Foco Principal | Exemplo de Evento | Exemplo de Command | KPI / SLO |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **M0** | Arquitetura | Fundação de Domínio & Sink | `SystemBootstrappedEvent` | `CreateTenantCommand` | Uptime API > 99.9% |
| **M1** | Observabilidade | Instrumentação OTel | `TelemetryEmittedEvent` | N/A | Tracing Coverage > 99% |
| **M2** | Monitoramento | Alertas & Golden Signals | `AlertFiredEvent` | `AcknowledgeAlertCommand` | MTTD < 5 min |
| **M3** | Correlação | Event Processing (CEP) | `IncidentCorrelatedEvent` | `CreateIncidentCommand` | MTTD < 60s / FPR < 5% |
| **M4** | Threat Intel | Feeds STIX/TAXII, IoCs | `IndicatorMatchedEvent` | `UpdateThreatIntelCommand` | Latência Enriquecimento < 500ms |
| **M5** | AI Advisory | IA Consultiva (Read-Only) | `SuggestionGeneratedEvent` | `RequestSuggestionCommand` | Acurácia Sugestão > 70% |
| **M6** | AI Copilot | Chat SOC em Linguagem Natural | `CopilotInteractionEvent` | Comandos em Lote via Chat | Redução MTTI em 40% |
| **M7** | Automação | Playbooks Determinísticos | `AutomationTriggeredEvent` | `ExecutePlaybookCommand` | Taxa de Sucesso > 95% |
| **M8** | Red Team | Simulação de Ataques | `DefenseGapIdentifiedEvent` | `SimulateAttackCommand` | Cobertura MITRE > 70% |
| **M9** | Autonomia | Resposta Ativa Adaptativa | `AutonomousDecisionExecutedEvent` | Commands com `requires_approval=false` | Taxa Autonomia > 95% |

## 2. Checklists do Processo de Governança

### Definition of Ready (DoR)
- [ ] ADR aprovado no Architecture Board.
- [ ] Eventos e Commands afetados modelados (M0.6/M0.7).
- [ ] Impacto no Banco de Dados (M0.4) validado.
- [ ] Threat Modeling realizado.

### Definition of Done (DoD)
- [ ] Cobertura de Testes > 90% (Unitários) e 80% (Integração).
- [ ] Testes de Contrato (Pact) aprovados.
- [ ] Traces e Métricas expostos via OpenTelemetry.
- [ ] Pipeline CI/CD com SAST/DAST sem bloqueios de segurança.
