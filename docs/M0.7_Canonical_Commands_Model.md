# M0.7 — Especificação Canônica do Modelo de Commands (CQRS)

**Versão:** 1.0.0  
**Status:** Aprovado pelo Comitê de Arquitetura

## 1. Conceito do Command
Um **Command** é uma estrutura de dados imutável que expressa uma intenção explícita de mutação de estado no sistema. 
Ao contrário de um Evento (que registra algo ocorrido no passado), o Command expressa uma intenção no presente/futuro que deve ser autorizada antes da execução.

$$ \text{Command} = (\text{Intent}, \text{Payload}, \text{Context}, \text{Metadata}, \text{Policies}) $$

## 3. Invariantes de Commands
- **INV-001 (UUID Obrigatório):** Todo Command possui um `command_id` único (UUID v4).
- **INV-002 (Tenant Obrigatório):** Pertence obrigatoriamente a um tenant válido.
- **INV-004 (Gera Audit Event):** Todo Command executado gera um `AuditEvent` imutável.
- **INV-005 (Policy Engine Mandatory):** Nenhum Command roda sem passar pela validação de políticas do Security Kernel.
- **INV-012 (Idempotência):** Todo Command deve possuir tratamento de deduplicação via `idempotency_key` (Sliding Window TTL).
